## Create a Virtual Environment

    python -m venv virenv

    virenv\Scripts\activate.bat    // activate the virenv

        <!-- Go to the next step, Befor you can create a requirements.txt file and in this file you can write the all required packages name like (Django,etc...), and then run next command -->

    pip install -r requirements.txt    // Install the required dependencies



## To run the server, run the following command:

    python manage.py makemigrations
        
    python manage.py migrate

    python manage.py runserver

    Open your web browser and go to: http://localhost:8000  //  http://127.0.0.1:8000/  

    python manage.py runserver 0.0.0.0:8000    // 

    Open your web browser and go to: http://localhost:8000  //  http://0.0.0.0:8000/

    Stop the Server : Ctrl+c
